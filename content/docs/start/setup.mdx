## Claude Code

Claude Code는 <Fact k="claude.plan" />가 필요합니다.

### 방법 1. 데스크톱 앱 (권장)

터미널을 쓰지 않아도 되어 비개발자에게 가장 편합니다.

<Steps>
<FdStep>
[claude.com/download](https://claude.com/download)에서 운영체제에 맞는 Claude 앱을 내려받아 설치합니다.
</FdStep>
<FdStep>
앱을 열고 Claude 계정으로 로그인합니다. 비밀번호와 인증은 본인이 직접 입력합니다.
</FdStep>
<FdStep>
상단의 **Code** 탭을 누르고, 작업할 폴더(예: 압축을 푼 실습 폴더)를 선택합니다.
</FdStep>
<FdStep>
입력창에 `이 폴더에 어떤 파일이 있는지 알려줘`라고 써 보세요. 답이 오면 설치 완료입니다.
</FdStep>
</Steps>

### 방법 2. 터미널 설치 (참고)

<OSBlock
  win={<>
    <p>시작 메뉴에서 <b>PowerShell</b>을 열고 아래를 붙여 넣습니다.</p>
    <pre><code>irm https://claude.ai/install.ps1 | iex</code></pre>
    <p>설치가 끝나면 <b>새 PowerShell 창</b>을 열고 <code>claude --version</code>으로 확인한 뒤, 작업 폴더에서 <code>claude</code>를 입력해 시작합니다.</p>
    <p>"claude를 찾을 수 없다"고 나오면 창을 닫고 새로 열어 보세요. 그래도 안 되면 <a href="https://code.claude.com/docs/en/troubleshoot-install">설치 문제 해결</a>을 확인합니다.</p>
  </>}
  mac={<>
    <p><b>터미널</b> 앱(응용 프로그램 → 유틸리티)을 열고 아래를 붙여 넣습니다.</p>
    <pre><code>curl -fsSL https://claude.ai/install.sh | bash</code></pre>
    <p>설치가 끝나면 새 터미널 창에서 <code>claude --version</code>으로 확인하고, 작업 폴더에서 <code>claude</code>를 입력해 시작합니다.</p>
  </>}
/>

출처: [Claude Code 공식 설치 문서](https://code.claude.com/docs/en/setup) (2026-10-06 확인)
